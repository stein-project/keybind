# Keybind 0.1.3: now an extra

Keybind no longer comes by default on new installs. Whoever already uses it keeps it, with the same keys and still updated.

- **Official extra**: to install it from scratch, add its source under Mods in the Stein Client.
- **Servers**: a server can turn off chat macros while you play there.
- **Update notice**: the Loader's Panel shows when a new version of this mod is out.
