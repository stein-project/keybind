# Keybind 0.1.3: agora um extra

O Keybind deixa de vir por padrão em instalações novas. Quem já usa continua com ele, com as mesmas teclas e sendo atualizado.

- **Extra oficial**: para instalar do zero, adicione a fonte dele em Mods no Stein Client.
- **Servidores**: um servidor pode desligar as macros de chat enquanto você joga nele.
- **Aviso de atualização**: o Painel do Loader mostra quando sai uma versão nova deste mod.
