# Keybind: chat messages and commands on a key

Requires Stein Loader 0.1.27.

New mod. Press a key and the game sends the message or command you chose, as if you typed it in the chat.

- **Binds in the Panel**: on the Keybind page, pick the key and write the text. Starting with `/` it goes as a command; otherwise as a message.
- **Several at once**: separate them with `|` (`/home | Good night, everyone`) and they go out one after the other.
- **With Ctrl, Shift or Alt**: the same key can have a bind on its own and another with the modifier; only the most specific one fires.
- **No spam kicks**: messages go out with a gap (half a second by default, adjustable under Sending) and the queue has a limit.
- **Only in game**: with the chat, the inventory or the Panel open, the key is yours. Holding it does not repeat.
- **Key in the square box**: each bind shows its key in the same square key box as the Combat key bindings.
