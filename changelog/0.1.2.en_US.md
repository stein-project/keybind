# Keybind 0.1.2: server rules

Some servers do not allow chat macros. Keybind now respects that on those servers, and only there.

- **Binds held where a server forbids them**: on a server that does not allow chat macros, your binds do nothing while you play there. They work again as soon as you leave, and nothing in your settings changes.
- **You know why**: the Keybind page says which server is holding them.
- **Needs Stein Loader 0.1.28**, which comes with the pack 0.1.36.
